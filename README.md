# neon_snake
Современная адаптация классической «Змейки» в неоновом стиле. Плавная анимация, адаптивный дизайн, управление с клавиатуры и свайпами, выбор сложности и таблица рекордов.

Добро пожаловать в Neon Snake — современную, стильную и полностью адаптивную переосмысление классической игры «Змейка». Погрузитесь в атмосферу ретро-футуризма с неоновым свечением, плавной анимацией и отзывчивым управлением на любом устройстве!

🚀 Особенности

* 🎨 **Неоновый визуал:** Стильная графика с эффектами свечения (glow) и теней.
* 🌊 **Плавная анимация:** Движение змейки интерполируется, что делает геймплей визуально приятным и современным.
* 📱 **Полная адаптивность:** Идеально подстраивается под любой экран — от широких мониторов до смартфонов.
* 🎮 **Универсальное управление:** 
  * *Desktop:* Клавиши `WASD` / `Стрелки`.
  * *Mobile:* Интуитивные свайпы по экрану.
* ⚙️ **Система сложности:** 4 уровня сложности, влияющие на скорость змейки.
* ⏸️ **Полный контроль:** Мгновенная пауза и быстрый перезапуск игры.
* 🏆 **Таблица рекордов:** Сохранение лучших результатов в `localStorage` браузера.

🕹️ Управление

💻 Для ПК / Ноутбуков:

* Движение: `↑` `↓` `←` `→` или `W` `A` `S` `D`
* Пауза / Продолжить: `Space` (Пробел) или `P`
* Перезапуск: `R`

📱 Для смартфонов и планшетов:

* Движение: Свайпы в любую из 4 сторон.
* Интерфейс: Используйте экранные кнопки для Паузы и Рестарта.

🛠️ Технологии

Проект создан с использованием современных веб-технологий:
* HTML5 (Canvas API для рендеринга)
* CSS3 (Анимации, Flexbox/Grid, неоновые эффекты)
* Vanilla JavaScript *(или укажи свой стек: React / Vue / TypeScript)*
* LocalStorage API (для сохранения рекордов)

📦 Запуск проекта

Чтобы запустить игру локально, выполните простые шаги:

1. Клонируйте репозиторий:
   
   ```bash
   git clone https://github.com/biterium/neon-snake.git
   
3. Перейдите в папку проекта:
   
   cd neon-snake

4. Откройте файл index.html в любом современном браузере.
   
(Если используеnt сборщик, например Vite/React, добавь сюда npm install и npm run dev).
